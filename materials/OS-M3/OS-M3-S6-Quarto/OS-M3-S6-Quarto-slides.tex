\subsection{Setting up Quarto}\label{setting-up-quarto}

During this session, we will be using Quarto from RStudio. To set up
Quarto, follow these steps:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Open RStudio
\item
  Install the most recent version of Quarto
  \href{https://quarto.org/docs/download/release.html}{here}
\item
  In RStudio, go to the Terminal tab and install
  \href{https://quarto.org/docs/output-formats/pdf-engine.html\#installing-tex}{tinytex}
  by typing \texttt{quarto\ install\ tinytex} into your terminal
\item
  Type \texttt{quarto\ -\/-version} into the terminal to check with
  version of Quarto you are using (should be 1.7 or higher)
\end{enumerate}

\begin{tcolorbox}[enhanced jigsaw, opacitybacktitle=0.6, toptitle=1mm, colbacktitle=quarto-callout-important-color!10!white, toprule=.15mm, left=2mm, colback=white, colframe=quarto-callout-important-color-frame, opacityback=0, bottomtitle=1mm, breakable, titlerule=0mm, rightrule=.15mm, arc=.35mm, title=\textcolor{quarto-callout-important-color}{\faExclamation}\hspace{0.5em}{Important}, bottomrule=.15mm, coltitle=black, leftrule=.75mm]

Make sure to have a recent version of
\href{https://www.r-project.org/}{R} (Version 4.4.3 or higher) and
\href{https://posit.co/download/rstudio-desktop/}{RStudio} (Version
2025.05.1+513 or higher) installed before you install/update Quarto. For
installing R and RStudio, see
\href{https://posit.co/download/rstudio-desktop/}{here}.

\end{tcolorbox}

\textbf{Speaker Notes}: During this session, we will be using Quarto
from RStudio. It is therefore necessary for you to have the most recent
version of R and RStudio installed. Then open RStudio and install Quarto
following the link. Finally, install tinytex, which is a small version
of TeX that can be used to build pdf documents with Quarto. You need to
install tinytex from the Terminal within RStudio by typing
\texttt{quarto\ install\ tinytex} into the terminal.

\textbf{Instructor Notes}: Leave enough time for the download and
installation of Quarto. Guide your students through the installation of
tinytex by showing them where to find the Terminal in RStudio. To see
which version of Quarto they already have installed, students can type
\texttt{quarto\ -\/-version} into the terminal. Quarto versions of 1.7
or higher are suitable for the rest of this tutorial. Quarto may fail or
behave unpredictably with older versions of R and RStudio, as newer
Quarto features and extensions rely on recent R releases and the current
RStudio. Keeping both up to date helps to avoid errors.

\textbf{Basic Markdown Text Formatting:}

\begin{itemize}
\tightlist
\item

\item

\item

\item

  → \st{text}
\item
  \texttt{Inline\ code:} \texttt{\textasciigrave{}code\textasciigrave{}}
  → \texttt{code}
\end{itemize}

Here is a link for the full list of markdown text shortcuts for

\end{tcolorbox}

\textbf{Speaker Notes}: With Markdown text, we can format text with very
simple symbols. It works the same way in both Source and Visual mode
with the only difference being how you see it while typing. In Source
mode you see the symbols, while in Visual mode it looks like regular
bold or italic text right away.

To make bullet points, add a single dash (\texttt{-}) before each point.
Make sure there is a blank line before the first and after the last
bullet points for it to render properly. To make a piece of text bold,
wrap it in double asterisks (\texttt{**}). For italics, wrap the text in
single asterisks (\texttt{*}). To strike through text, wrap it in double

\item

\textbf{Speaker Notes}: You can insert a link with a title using square

link without a title by simply wrapping the URL in angle brackets
(\textless\ldots\textgreater). This shows the raw link, which is fine if
the URL itself is clear and concise enough. A good rule of thumb is to
use titled links for readability, and untitled links when you want to
show the exact URL.

accessibility, since captions explain the relevance of the image. It is
also useful in reports, presentations, or academic writing where figures
must be labeled.

\textbf{Speaker Notes}: GitHub Pages makes it possible to publish Quarto

\item
  You can also use the quarto publish command, which pushes your
  rendered site to GitHub Pages automatically.

  \begin{itemize}
  \tightlist
  \item
    For a more advanced setup, you can use GitHub Actions so that every
    time you push changes to your repository, the site automatically
    re-renders and updates online.
  \end{itemize}
\item
  Whichever method you use depends on how automated you want the process
  to be.
\end{itemize}

Adding a \texttt{.nojekyll} file to the root of your repository tells
GitHub Pages not to do additional processing of your published site
using Jekyll

\end{tcolorbox}

\textbf{Speaker Notes}: Here, we're setting up the basic project files
GitHub Pages needs in order to publish our Quarto website. First, we'll
create a \texttt{\_quarto.yml} file using the Terminal. This file tells
Quarto that the project is a website and that the rendered output should
go into the docs folder. Next, we'll add a special file called
\texttt{.nojekyll}. By default, GitHub Pages uses Jekyll to process
websites, but that can interfere with Quarto's output. Adding a
\texttt{.nojekyll} file tells GitHub Pages to leave our site exactly as
Quarto created it.

\subsection{Recap}\label{recap}

\begin{itemize}
\tightlist
\item
  \textbf{Quarto} is a powerful tool that combines text, code, and media
  to make documents more transparent, reproducible, and accessible.
\item
  Within a \textbf{.qmd file}:

  \begin{itemize}
  \tightlist
  \item
    The \textbf{YAML header} controls the document settings, such as how
    code chunks are displayed.
  \item
    \textbf{Code chunks} run code and show results.
  \item
    \textbf{Markdown text} creates the main content and can be formatted
    using keyboard shortcuts.
  \end{itemize}
\item
  Use Quarto directly with \textbf{Zotero} for inserting and managing
  references.
\item
  Make your work accessible and reproducible by publishing on platforms,
  such as \textbf{GitHub Pages}, your own \textbf{website} or
  \textbf{Quarto Pub}.
\end{itemize}

Download the Quarto cheatsheet

\textbf{Speaker Note}: Here are some of the key things covered in the
lesson that give a general overview of Quarto and what it contains.
Quarto is more than just a tool to write documents, it's designed to
bring together text, code, and media in one .qmd file that ensures
transparency and reproducibility. It makes writing cleaner and more
efficient without the need for complex styling tools. Zotero integration
streamlines citation management and bibliography building, which is
essential for academic and research writing. Quarto enables sharing work
through platforms like Quarto Pub or GitHub Pages, which makes research
accessible and reproducible. - For quick reference, a downloadable
cheatsheet is provided with this lesson. It offers beginner-friendly
instructions summarizing the key terms, features, and functions of
Quarto.
